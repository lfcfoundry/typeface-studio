# Third-party notices

Typeface Studio bundles **fontsketch 0.1.0**, copyright Alexandre Kohler, under the MIT License. Its source and license are available at <https://github.com/kwy404/fontsketch>. Fontsketch's TTF compiler is used for TrueType outline and SFNT generation. Its browser application is not loaded from that upstream URL; the package is included in the generated HTML bundle.

The exact upstream MIT license is also included in a collapsible notice inside `dist/typeface-studio.html` and the isolated contour prototype bundle.

The fontsketch package declares `brotli-wasm` as an Apache-2.0 dependency for optional WOFF2 operations. Typeface Studio only uses TTF operations; the build should tree-shake unused WOFF2 functionality. If the final bundle contains any of that dependency, the corresponding license notice must be included here and its code remains bundled locally.

The isolated prototype additionally bundles `compromise@14.19.0` (MIT), with its runtime dependencies `efrt@2.9.0` (MIT) and `suffix-thumb@6.0.0` (MIT). Their notices are included in the prototype HTML bundle. The prototype build also uses the repository-pinned `esbuild@0.25.12` as a build-time tool; esbuild is not a runtime dependency.

The six checked-in TTFs under `prototype/artifacts/` are generated by the project’s own procedural recipes. They are not redistributed reference fonts or third-party outlines. No cloud service or runtime network dependency is used by either browser application.
